# Instruções para agentes Codex

No início de cada tarefa neste projeto, leia `AI_HANDOFF.md` e confirme seu conteúdo
com `git status --short` e os diffs relevantes. O Git é a fonte da verdade.

Preserve alterações não commitadas de outros agentes. Ao concluir uma etapa relevante,
atualize no handoff somente fatos verificáveis, testes executados, pendências e uma
entrada curta no diário identificada como `Codex`. Nunca registre segredos, conteúdo de
`.env`, dados pessoais ou raciocínio interno.
