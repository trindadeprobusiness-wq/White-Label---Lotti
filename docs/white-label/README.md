- `../../api/prisma/tenant-foundation.md`: contrato de fundação multi-tenant.
- `g2-model-matrix.md`: matriz dos modelos Prisma.
- `g2-backend-surface-inventory.md`: inventário das superfícies Backend.

Os arquivos foram copiados do workspace de Engenharia sem substituir os originais. Decisões, ressalvas e gates registrados neles continuam vigentes; sua presença neste repositório não libera migration, rollout ou produção.
